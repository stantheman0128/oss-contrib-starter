## 預設約束

- 使用者環境：**macOS + 繁體中文**
- `gh` 搜尋：**串行**，不要平行打爆 rate limit
- 先選題與重現，**未經使用者同意不要** `gh pr create`／乱留言
- 禁止教使用者假裝 maintainer、刷量、多帳號騙福利
- 特化請依 macOS／繁中建立，**不要**叫使用者去做別人的 Windows／cp950 題當主線

## 常用指令（對使用者說）

- 「幫我選題」→ 遵守 SELECT-TICKETS，輸出 2–3 候選 + 風險  
- 「幫我準備 PR」→ 用 templates/PR-body.md，跑真實驗證  
- 「評估 Codex 申請」→ 整份遵守 [CODEX-OSS-APPLY.md](CODEX-OSS-APPLY.md)
